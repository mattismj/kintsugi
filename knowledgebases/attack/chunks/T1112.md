The Windows registry stores configuration for the operating system, its services,
and installed applications. Adversaries modify it to change how a system behaves,
to hide configuration from casual inspection, to weaken security tooling, and to
store payload data. Some keys require elevated rights, so a write from a
user-context process to a machine-wide key is itself notable. Detection is closer
to maintaining a baseline of expected values for sensitive keys than to matching a
single known-bad value.
