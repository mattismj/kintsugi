Web protocols carry most normal enterprise traffic, so command and control over
HTTP, HTTPS, or WebSocket blends in with it. Adversaries shape requests to look
like ordinary application traffic: standard ports, plausible headers and user
agents, and URIs that match the target application. Data is carried in request
and response bodies, sometimes inside cookies or parameters. Detections lean on
request regularity, a beacon that keeps a fixed cadence, and a host talking to a
destination no other host talks to.
