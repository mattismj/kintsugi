Windows runs programs listed in the registry Run and RunOnce keys, and in the
user's Startup folder, when a user logs on. Adversaries add an entry there so
their program starts automatically, either as a direct payload or as a legitimate
utility that loads further code. Many installers write to the same locations, so
presence alone is not proof of anything. The signal is an unfamiliar entry, or one
whose command points at a user-writable or temporary directory.
