PowerShell is a Windows command-line shell and scripting language built on .NET,
and it ships with the operating system. Adversaries abuse it to run commands and
scripts, download and execute payloads, and reach system APIs without writing a
dedicated tool to disk. Because it is a legitimate administrative component, its
use blends with normal host maintenance. Common signals are encoded or hidden
invocations, download-and-execute one-liners, and script blocks that never touch
the filesystem.
