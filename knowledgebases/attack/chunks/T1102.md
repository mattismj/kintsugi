Adversaries may use legitimate, publicly available web services — cloud storage,
paste sites, social media, and developer platforms — for command and control or for
hosting payloads. Because the traffic goes to a well-known service, blocking it
costs the defender real functionality, and the connection itself is not obviously
malicious. Content can be embedded in posts, comments, or file metadata, so the
channel survives inspection of the endpoint alone. Beaconing to a storage or paste
endpoint, or a host pulling script content from a social platform, is the signal.
