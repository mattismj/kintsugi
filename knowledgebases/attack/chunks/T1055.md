Process injection runs code inside the address space of another process, so the
payload executes under that process's identity and inherits its access. Variants
include injecting shellcode or a library into a running process, hijacking a
thread, and writing to remote process memory. When the target process is more
privileged, injection also becomes a privilege escalation step. Cross-process
memory writes, remote thread creation, and modules loading from unexpected paths
are the typical detections.
