The Windows command shell, cmd.exe, is the operating system's command
interpreter. Adversaries use it to run commands, drive batch files, and launch
other processes, often as the first interpreter reached through a remote shell, a
scheduled task, or a service. Command shell activity frequently chains built-in
utilities instead of dropping a dedicated tool, which keeps the footprint small.
Parent-child process relationships and long command lines assembled from native
binaries are the usual signal.
