Adversaries copy tools or payloads from an external system into the compromised
environment rather than carrying them in with the initial access. Transfers may
use built-in utilities such as curl, wget, certutil, or PowerShell, a file-sharing
service, or the existing command and control channel. The transferred file is
usually executed or loaded shortly afterwards. An outbound fetch followed by
execution from a download, temporary, or user-writable directory is the typical
signal.
