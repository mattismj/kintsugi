# kintsugi-pack

Persona pack management.

## Synopsis

```bash
kintsugi pack list
kintsugi pack show <persona>
```

## Description

Manage the persona pack. Personas define the agent's behavior and personality.

## Commands

- **list** - Show personas and their match rules
- **show** - View a persona's full definition

## Examples

List personas:

```bash
$ kintsugi pack list
```

View a persona:

```bash
$ kintsugi pack show coder
```
