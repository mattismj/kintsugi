# kintsugi-report

Findings report.

## Synopsis

```bash
kintsugi report [--out <file>]
```

## Description

Generate a plain-text findings report including findings, telemetry, and quota.

## Options

- `--out` - Output file (default stdout)

## Examples

Print report:

```bash
$ kintsugi report
```

Save to file:

```bash
$ kintsugi report --out report.txt
```
