# kintsugi-init

Scaffold a workspace.

## Synopsis

```bash
kintsugi init [--force]
```

## Description

Draft CONTEXT.md and kintsugi.toml from the current directory tree.

## Options

- `--force` - Overwrite existing files

## Examples

Initialize a workspace:

```bash
$ kintsugi init
```

Force reinitialize:

```bash
$ kintsugi init --force
```
