# kintsugi-persona

Persona triggers.

## Synopsis

```bash
kintsugi persona triggers [--apply]
```

## Description

Propose trigger-map entries from refusal telemetry. Triggers map refusal terms to alternative responses.

## Options

- `--apply` - Write the proposed triggers

## Examples

View proposed triggers:

```bash
$ kintsugi persona triggers
```

Apply triggers:

```bash
$ kintsugi persona triggers --apply
```
