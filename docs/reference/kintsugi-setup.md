# kintsugi-setup

Install persona pack and global config.

## Synopsis

```bash
kintsugi setup [--model <ref>]
```

## Description

Install the persona pack and global AGENTS.md/config.

## Options

- `--model` - Default model reference

## Examples

Run setup:

```bash
$ kintsugi setup
```

Set default model:

```bash
$ kintsugi setup --model ollama/llama3
```
