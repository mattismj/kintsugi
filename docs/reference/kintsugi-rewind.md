# kintsugi-rewind

Rewind to a checkpoint.

## Synopsis

```bash
kintsugi rewind <id> <ckpt-id>
```

## Description

Mark a session as rewound to a checkpoint. The checkpoint becomes the resume history.

## Examples

Rewind to a checkpoint:

```bash
$ kintsugi rewind abc123 ckpt-456
```
