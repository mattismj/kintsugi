# kintsugi-lab

Compose lab management.

## Synopsis

```bash
kintsugi lab up
kintsugi lab down
kintsugi lab status
```

## Description

Bring up, tear down, or inspect the compose lab. Labs are synthetic, egress-free environments for testing.

## Commands

- **up** - Bring up the lab
- **down** - Tear down the lab
- **status** - Inspect the lab

## Examples

Start the lab:

```bash
$ kintsugi lab up
```

Check status:

```bash
$ kintsugi lab status
```

Stop the lab:

```bash
$ kintsugi lab down
```
