# kintsugi-skills

Workspace skills.

## Synopsis

```bash
kintsugi skills list
kintsugi skills show <name>
```

## Description

List and view workspace skills. Skills are markdown files that teach the agent how to perform specific tasks.

## Commands

- **list** - Show skills with name, description, path
- **show** - Print a skill's full body

## Examples

List skills:

```bash
$ kintsugi skills list
```

View a skill:

```bash
$ kintsugi skills show git-commit
```
